<h1>Relatório do Projeto MVC</h1>
Aluno: Fernando Ancioto Filho <br>
Este é um projeto que esta sendo construído com o intuito de aprender como funciona a arquitetura MVC na prática.

## Até o momento foram feitas as seguintes ações:

- Instalação do Java na versão `21`
- Importação do **Spring Boot** configurado usando **Maven**, usando as dependências `thymeleaf`, `spring boot dev tools` e `spring boot web`
- Criação do **Controller** com o método `@GetMapping`
- `index.html` para a exibição na web

## Durante esse processo alguns erros ocorreram.

Inicialmente o projeto seria desenvolvido em Java `25`, porém, por algum erro de configuração do ambiente, essa versão não funcionou corretamente, o que levou a construção a ser realizada na versão `21`.

Também, quando o `index.html` foi criado, não colocado na pasta adequada, o que resultou em um erro de exibição. Esse foi corrigido movendo o arquivo para a pasta `templates`.
